# تحقق قابلية تشغيل MCP البعيد

آخر تحقق تقني: ٨ سبتمبر ٢٠٢٦ (من دون حسابات عملاء أو تفويض مستخدم حي).

## النتائج المثبتة

- `GET https://mcp.albayan-journal.org/mcp` يعيد `401` مع
  `WWW-Authenticate` يشير إلى
  `https://mcp.albayan-journal.org/.well-known/oauth-protected-resource/mcp`.
- بيانات المورد المحمي تعيد `200` وتعلن المورد الرسمي نفسه، وخادم التفويض
  `https://clerk.albayan-journal.org/`، والنطاقات `openid profile email`،
  والمصادقة بترويسة Bearer.
- بيانات خادم التفويض تعلن نقاط authorization وtoken وrevocation، ونقطة
  التسجيل الديناميكي `/oauth/register`، وPKCE بطريقة `S256`، ومنحتي
  `authorization_code` و`refresh_token`.
- خادم التفويض يعلن `offline_access` ضمن النطاقات المدعومة. هذا يثبت توفر
  عناصر الاكتشاف اللازمة للتجديد، لكنه لا يثبت دورة تجديد فعلية دون تفويض حي.
- المصدر المحلي يسجل أداتي `get_my_profile` و`read_articles` فقط، وكلتاهما
  تستدعيان مسارات `GET` في FastAPI.

## نتائج غير متحققة

- تسجيل الدخول والموافقة واستدعاء الأدوات وتجديد التوكن فعليًا من Cursor.
- تدفق OAuth/DCR الحي من Antigravity وOpenCode.
- إعادة اختبار Claude وChatGPT بحسابات فعلية.
- الفحص البصري المتجاوب؛ لم تتوفر جلسة متصفح في بيئة التحقق.

لا يجوز وصف البنود السابقة بأنها ناجحة حتى تُنفذ بحسابات اختبار مناسبة.

## مانع نشر مكتشف

تعذر حل `api.albayan-journal.org` عبر DNS وقت التحقق (`curl: Could not
resolve host`). يجب إعداد DNS والشهادة ومسار الاستضافة لهذا النطاق، ثم التحقق
من استجابة FastAPI ومن أن خدمة MCP تستخدمه أو تستخدم مسارًا خادميًا صالحًا قبل
اعتبار الانتقال إلى النطاقات الرسمية مكتملًا في الإنتاج.

## حالة CI

المستودع العام يعرض GitHub Actions وتشغيلات سابقة ناجحة، لكنها تخص تغييرات
أخرى. هذه التغييرات المحلية لم تُدفع إلى فرع أو PR، ولذلك لا توجد نتيجة CI
خاصة بها بعد.
