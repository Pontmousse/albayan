# خطوط معاينة رموز المعادلات

يعتمد **عرض المعادلات نفسه** على BuTeX؛ وBuTeX v7.1.0 يضمّن ملفات الخطوط في حزمة `dist` كـ data URLs، لذلك لا تعتمد دلالات `\\butex...` ولا تصيير BuTeX على هذه النسخ الموجودة في `public/`.

هذه الملفات مطلوبة فقط لكي تعرض واجهة اختيار الخط في البيان معاينة بصرية مطابقة للخط المختار. ضع النسخ المصرح باستخدامها مباشرة داخل `frontend/public/` وبالأسماء الأصلية التالية:

- `Takween.otf`
- `Diwani Letter Regular.ttf`
- `DWNOUTSH.TTF`
- `Almaghribi-Warsh-Quran.otf`

ملف `Almaghribi-Warsh-Quran.otf` موجود بالفعل في المستودع. عند غياب أحد الملفات الأخرى ستبقى الواجهة قابلة للاستخدام، لكن معاينة ذلك الخط ستسقط إلى خط عربي بديل حتى يُضاف الملف.

تستخدم الواجهة هذه المعاينات فقط؛ أما القيم المحفوظة فتستخدم أوامر BuTeX القياسية:

- `\\text{...}` — الافتراضي
- `\\butextakween{...}` — تكوين
- `\\butexdiwani{...}` — ديواني
- `\\butexdiwanioutline{...}` — ديواني مزخرف
- `\\butexmaghribi{...}` — مغربي
- قيمة خام بلا تغليف — بدون تنسيق
